使用方法：

1. index.html、style.css、app.js、manifest.jsonを同じフォルダに置く。

2. imagesフォルダを作成する。

3. OGP画像をimages/ogp.jpgとして保存する。

4. 活動写真をimages/dx-suzuki-01.jpgから
   images/dx-suzuki-06.jpgまでの名前で保存する。

5. GitHubに保存して公開する。

6. 公開ページをスマートフォンで確認する。
